# KR1878VE1 Toolkit

Инструментальный комплекс для микроконтроллера **КР1878ВЕ1** (TESSA):
ассемблер, программатор, симулятор и настольный интерфейс — всё в одном
рабочем процессе.

Проект — результат исследования и реверс-инжиниринга оригинального тулчейна
(см. `docs/REVERSE_ENGINEERING.md`). Поддерживается работа и с настоящим
LPT-программатором, и с полностью симулированным чипом.

---

## Возможности

- **Ассемблер `.mic`** — двухпроходная сборка с макросами, `#define`,
  `#include`, условными директивами, локальными и глобальными метками,
  листингом и таблицей символов.
- **CLI** — `assemble`, `read`, `write`, `verify` поверх трёх бэкендов:
  - `mock` — в памяти (для тестов и CI);
  - `sim` — полный протокольный путь без железа, состояние сохраняется
    в файл `.sim` и переживает запуски;
  - `lpt` — физический параллельный порт (Linux/FreeBSD, x86-64).
- **Настольное приложение (Tauri 2 + SvelteKit)** — редактор исходников,
  сборка, программирование/проверка/чтение устройства, дамп памяти и
  data EEPROM, выбор бэкенда и файла состояния.
- **Форматы файлов** — `.sav` (образ команд), `.dat` (data EEPROM),
  `.arp` (фазовые ворота программатора), `.sim` (снапшот устройства).
- **Протокол** — одноклоковый битбанг, командные/стирающие импульсы,
  CRC-16/CCITT, канал OSC/config, симулятор и адаптер полярности.

## Статус

- Блоки 1–4 (lint-гигиена, протокол, интеграционное покрытие, CLI, desktop UI)
  реализованы; **81** тест зелёный, clippy `-D warnings` чистый.
- **Требуется проверка на железе**: полярность BUSY/ACK и тайминги LPT
  смоделированы, но не подтверждены на физическом программаторе
  (`docs/adr/ADR-004-lint-and-testutil.md` §2).

## Быстрый старт (CLI)

```sh
cargo run -- assemble demo.mic --out demo.sav
cargo run -- write demo.mic --backend sim --sim-state chip.sim --osc 3
cargo run -- verify demo.mic --backend sim --sim-state chip.sim
cargo run -- read --backend sim --sim-state chip.sim --out dump.sav
```

## Настольное приложение

```sh
cd desktop
npm install
npm run tauri dev          # режим разработки
npm run tauri build        # релизная сборка
```

## Структура

```
crates/
  core/        # модель памяти, типаж Backend, операции program/verify/read
  protocol/    # нижний протокольный слой (битбанг, CRC, Device, симулятор)
  assembler/   # .mic -> MemoryImage + листинг + символы
  programmer/  # бэкенды: Mock / Sim / LPT
  file-format/ # .sav, .dat, .arp, .sim
  cli/         # консольный интерфейс
desktop/       # Tauri 2 + SvelteKit UI
docs/          # исследование, стандарты, ADR, форматы файлов
```
