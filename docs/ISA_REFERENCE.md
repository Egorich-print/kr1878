# ISA_REFERENCE.md — Система команд КР1878ВЕ1 (справочник)

> Полный справочник по архитектуре и системе команд микроконтроллера
> КР1878ВЕ1 (ядро ТЕСЕЙ). Составлен **по собственным исследованиям**: таблицы
> кодировок сверены с реализацией в `crates/core/src/isa.rs` и проверены
> юнит-тестами энкодера; семантика — по наблюдаемому поведению инструментов и
> нашим симуляторам (`crates/protocol`, `crates/programmer`).
>
> **Авторско-правовая справка.** Это оригинальный справочник, излагающий
> *факты* (мнемоники, кодировки, модель памяти). Факты и функциональные
> характеристики авторским правом не охраняются. Текст составлен своими словами,
> таблицы построены заново и не копируют фрагменты документов производителя;
> источник фактов — обратное проектирование и анализ (см.
> `docs/REVERSE_ENGINEERING.md`). Единственный авторитетный источник кодировок в
> этом репозитории — исполняемый код `crates/core/src/isa.rs`.

## 1. Архитектура (кратко)

| Параметр | Значение |
|----------|----------|
| Ядро | ТЕСЕЙ, CMOS, Гарвардская архитектура, RISC |
| Команда | фиксированная, **16 бит** (1 слово = 1 команда) |
| Память команд | ЭСППЗУ **1К × 16** (адрес 10 бит); первые 16 слов — векторы прерываний |
| Память данных | единое пространство 256 байт: периферия 0x00–0x3F, ОЗУ 0x40–0xBF, ЭСППЗУ данных 0xC0–0xFF (64 байта) |
| Регистровый файл | нет классических РОН; 32 виртуальных 8-бит регистра через 4 окна A/B/C/D по 8 байт |
| Исполнение | любой команды = 2 такта; реакции на прерывание = 3 такта |
| Тактовая частота | 32 кГц … 8 МГц |
| Команд | 52 |
| Стеки | командный 8×10 (ISP), данных 16×8 (DSP) |

### 1.1 Операнды: сегменты и окна

Поле операнда — **5 бит**: `bit4-3` — сегмент (00=A, 01=B, 10=C, 11=D),
`bit2-0` — индекс 0..7 внутри окна. Эффективный адрес в памяти данных =
(база сегмента из `SR0..SR3`) + индекс.

| Синтаксис | Операнд |
|-----------|---------|
| `%a0` … `%a7` | окно A, байт 0..7 (префикс `%` необязателен) |
| `%b0` … `%b7` | окно B |
| `%c0` … `%c7` | окно C |
| `%d0` … `%d7` | окно D; **`d6` и `d7` — косвенная адресация** через IR0/IR1 |

Косвенная адресация (окно D):
- `%d6` → IR0, `%d7` → IR1 (регистры косвенной адресации).
- Режимы IR0/IR1: выключен / автоинкремент / автодекремент (±1 после доступа);
  выбор режима — через `ldr` (старшие биты).
- IR1 умеет адресовать **память команд** (байтовый адрес = `SR6` + 3 младших
  бита `SR7`), с автоинкрементом.

### 1.2 Сервисные регистры SR0–SR7

| № | Название | Функция |
|---|----------|---------|
| 0 | SR0 | база сегмента A |
| 1 | SR1 | база сегмента B |
| 2 | SR2 | база сегмента C |
| 3 | SR3 | база сегмента D |
| 4 | SR4 | IR0 — адрес (часть) |
| 5 | SR5 | IR0 — адрес (часть) |
| 6 | SR6 | IR1 — адрес (старший байт; режим памяти команд) |
| 7 | SR7 | IR1 — адрес (младшие 3 бита в режиме памяти команд) |

Доступ к SR — только `ldr`, `mfpr`, `mtpr`, `push`, `pop`.

### 1.3 Регистр состояния процессора (RS)

```
 7    6    5    4    3    2    1    0
RES  RES  DC   OF   IE   S    Z    C
```

| Бит | Имя | Смысл |
|-----|-----|-------|
| 0 | C | перенос |
| 1 | Z | ноль |
| 2 | S | знак |
| 3 | IE | разрешение прерываний (ставится `wait`/`stop`/`sst`) |
| 4 | OF | арифметическое переполнение |
| 5 | DC | десятичный (полубайтовый) перенос |
| 6–7 | RES | зарезервированы |

OF и DC «одноразовые»: ставятся арифметикой, сбрасываются следующей командой;
проверяются через `tof`/`tdc` (перенос в Z). RS читается по физическому адресу
памяти **0x00**. На прерывании RS автоматически сохраняется в стек данных,
`rti` восстанавливает.

## 2. Форматы команд (кодировки)

Все команды — 16-битные слова. Бит 15 — старший.

### 2.1 Двухоперандные
```
биты 15..10 | 9..5    | 4..0
opcode (6)  | src (5) | dst (5)
```
Применяется к: `mov cmp sub add and or xor`.

### 2.2 Литеральные с 8-битной константой
```
биты 15..13 | 12..5      | 4..0
opcode (3)  | const (8)  | dst (5)
```
Применяется к: `movl cmpl` (8-битная константа).

### 2.3 Литеральные с 5-битной константой
```
биты 15..10 | 9..5         | 4..0
opcode (6)  | sconst (5)   | dst (5)
```
Применяется к: `addl subl`.

### 2.4 Тетрадные (битовые маски)
```
биты 15..10 | 9      | 8..5    | 4..0
opcode (6)  | p (1)  | tetrad (4) | dst (5)
```
`p=1` — старшая тетрада (мнемоники `*H`), `p=0` — младшая (`*L`).
Применяется к: `bic bis btg btt`.

### 2.5 Однооперандные
```
биты 15..5 | 4..0
opcode (11)| dst (5)
```
Применяется к: `swap neg not shl shr shra rlc rrc adc sbc`.

### 2.6 Сервисные регистры / RS

| Команда | Кодировка | Действие |
|---------|-----------|----------|
| `ldr n,const` | `00100` + const(8) + n(3) | const → SR[n] |
| `mfpr d,n` | `00000011` + n(3) + d(5) | SR[n] → d |
| `mtpr n,s` | `00000010` + n(3) + s(5) | s → SR[n] |
| `push n` | `0000000000010` + n(3) | SR[n] → стек данных; DSP+1 |
| `pop n` | `0000000000011` + n(3) | стек → SR[n]; DSP−1 |
| `sst m` | `000000011000` + m(4) | установить биты RS |
| `cst m` | `000000011100` + m(4) | сбросить биты RS |

### 2.7 Передача управления
```
биты 15..10 | 9..0
opcode (6)  | addr (10)
```
Применяется к: `jmp jsr jz jnz js jns jc jnc` (безусловные/условные по RS).

### 2.8 Фиксированные слова (без операндов)

| Мнемоника | Слово | Действие |
|-----------|-------|----------|
| `nop` | 0x0000 | нет операции |
| `wait` | 0x0001 | ждать прерывания; IE=1 |
| `reset` | 0x0002 | ISP=0, DSP=0; сброс stack-fault |
| `ijmp` | 0x0003 | IR1(младшие 10 бит) → PC |
| `tof` | 0x0004 | OF → Z |
| `tdc` | 0x0005 | DC → Z |
| `sksp` | 0x0006 | ISP−1 (выброс уровня возврата) |
| `ijsr` | 0x0007 | PC→стек; IR1→PC; ISP+1 |
| `stop` | 0x0008 | остановка; генератор выкл; IE=1 |
| `rts` | 0x000C | стек→PC; ISP−1 |
| `rti` | 0x000D | стек→PC; стек→RS; ISP−1, DSP−1 |
| `rtsc c` | 0x000E / 0x000F (LSB=c) | стек→PC; c→C; ISP−1 |

## 3. Полный список команд

### 3.1 Двухоперандные (7)

| Мнемоника | Код (6 бит) | Действие | Влияние на RS |
|-----------|------------|----------|---------------|
| `mov d,s` | `000001` | s → d | Z,S; OF=0 |
| `cmp d,s` | `000010` | d − s (без записи) | S,Z,C,OF,DC |
| `sub d,s` | `000011` | d − s → d | S,Z,C,OF,DC |
| `add d,s` | `000100` | d + s → d | S,Z,C,OF,DC |
| `and d,s` | `000101` | d & s → d | Z,S; C=0,OF=0,DC=0 |
| `or d,s` | `000110` | d \| s → d | Z,S; C=0,OF=0,DC=0 |
| `xor d,s` | `000111` | d ^ s → d | Z,S; C=0,OF=0,DC=0 |

### 3.2 Литеральные (6)

| Мнемоника | Код | Диапазон константы | Действие |
|-----------|-----|---------------------|----------|
| `movl d,const` | `010` (3 бита) | 0..255 | const → d (`clr` ≡ `movl d,0`) |
| `cmpl d,const` | `011` (3 бита) | 0..255 | d − const → RS |
| `addl d,sconst` | `001100` | 0..31 | d + sconst → d (`inc` ≡ `addl d,1`) |
| `subl d,sconst` | `001011` | 0..31 | d − sconst → d (`dec` ≡ `subl d,1`) |
| `bic d,tconst` | `001010` | 0..15 (+p) | d & ~tconst → d |
| `bis d,tconst` | `001110` | 0..15 (+p) | d \| tconst → d |
| `btg d,tconst` | `001111` | 0..15 (+p) | d ^ tconst → d |
| `btt d,tconst` | `001101` | 0..15 (+p) | d & tconst → Z,S |

Тетрадные имеют по два варианта по положению тетрады `p`:
`bicl/bich`, `bisl/bish`, `btgl/btgh`, `bttl/btth`.

### 3.3 Однооперандные (10)

| Мнемоника | Код (11 бит) | Действие | Влияние на RS |
|-----------|--------------|----------|---------------|
| `swap d` | `00000000001` | обмен тетрад | Z,S; C=OF=DC=0 |
| `neg d` | `00000000010` | −d → d | Z,S,OF,C,DC |
| `not d` | `00000000011` | ~d → d | Z,S; OF=0 |
| `shl d` | `00000000100` | сдвиг влево; 0→d0; d7→C | Z,S; C=d7; DC=0 |
| `shr d` | `00000000101` | сдвиг вправо логич.; d0→C | Z; S=0; C=d0 |
| `shra d` | `00000000110` | сдвиг вправо арифм. | Z,S; C=d0 |
| `rlc d` | `00000000111` | вращение влево через C | Z,S; C=d7 |
| `rrc d` | `00000001000` | вращение вправо через C | Z,S; C=d0 |
| `adc d` | `00000001001` | d + C → d | Z,S,OF,C,DC |
| `sbc d` | `00000001010` | d − C → d | Z,S,OF,C,DC |

### 3.4 Сервисные регистры и RS (9)

`ldr mfpr mtpr push pop sst cst tof tdc` — см. §2.6.

### 3.5 Передача управления (10)

| Мнемоника | Код (6 бит) | Условие перехода |
|-----------|------------|------------------|
| `jmp a` | `1000` | безусловный |
| `jsr a` | `1001` | вызов подпрограммы |
| `jz a` / `jeq a` | `1010` | Z=1 |
| `jnz a` / `jne a` | `1011` | Z=0 |
| `jns a` | `1100` | S=0 |
| `js a` | `1101` | S=1 |
| `jnc a` | `1110` | C=0 |
| `jc a` | `1111` | C=1 |

Адрес — 10 бит (0..1023), абсолютный в памяти команд.

### 3.6 Фиксированные (12)

`nop wait reset ijmp tof tdc sksp ijsr stop rts rti rtsc` — см. §2.8.

## 6. Язык ассемблера (директивы и препроцессор)

Реализация: `crates/assembler` (двухпроходная сборка, листинг, таблица символов).

### 6.1 Директивы резервирования данных

| Директива | Описание |
|-----------|----------|
| `.byte const[, const…]` | резервирует байты данных (младший байт слова) |
| `.word const/метка[, …]` | резервирует 16-битные слова |
| `.even` | выравнивание по чётному адресу |
| `.= expr` | установить текущий счётчик команд |
| `.end` / `.list` | конец исходника / управление листингом |

### 6.2 Препроцессор

| Синтаксис | Описание |
|-----------|----------|
| `#define NAME значение` | текстовая подстановка констант |
| `#include "файл"` | включение модуля |
| `.macro имя [парам…]` … `.endmacro` | макроопределение с параметрами |
| `.if expr` / `.else` / `.endif` | условная компиляция |

### 6.3 Константы и система счисления

| Суффикс | Основание | Пример |
|---------|-----------|--------|
| `h` / `H` | 16 | `24h`, `0FFh` |
| `o` / `O` | 8 | `777o` |
| `b` / `B` | 2 | `1010b` |
| (нет) | 10 | `123` |

### 6.4 Комментарии

`;` — комментарий до конца строки.

### 6.5 Структура программы

Первые 16 слов памяти команд (0x000–0x00F) зарезервированы под векторы
прерываний (таблица в §7). Типичный каркас:

```asm
; --- векторы прерываний ---
        jmp     start           ; 0x000  начальный запуск
        nop                     ; 0x001  системная ошибка
        nop
        jmp     wdt_isr         ; 0x003  сторожевой таймер
        nop
        nop
        jmp     porta_isr       ; 0x006  порт A
        jmp     portb_isr       ; 0x007  порт B
        .word   0xFFFF          ; 0x008..0x00E
        jmp     timer_isr       ; 0x00F  таймер / запись ЭСППЗУ

; --- программа ---
start:
        ldr     #0, 0x40        ; база сегмента A → ОЗУ 0x40
        movl    %a1, 24h
loop:
        inc     %a1
        jmp     loop
```

## 7. Векторы прерываний

| Адрес слова | Источник |
|-------------|----------|
| 0 | начальный запуск (reset) |
| 1 | системная ошибка (в т.ч. stack-fault) |
| 3 | сторожевой таймер |
| 6 | порт A |
| 7 | порт B |
| 15 (0x0F) | таймер + завершение записи ЭСППЗУ |

## 8. Связь с реализацией

- **Энкодер команд (единственный авторитетный источник кодировок в этом
  репозитории):** `crates/core/src/isa.rs` — `Instruction` enum + `encode()`;
  все кодировки в таблицах выше покрыты юнит-тестами (`isa.rs::tests`).

- **Модель памяти:** `crates/core/src/memory.rs` — `MemoryImage`
  (1024 слова программы, 64 байта ЭСППЗУ данных, config-байт).
- **Форматы файлов:** `docs/FILE_FORMATS.md` (`.sav`, `.dat`, `.sim`, `.arp`).
- **Протоколы программаторов:** `docs/HARDWARE_PROTOCOL.md` (LPT §1–5, USB §7).

## 9. Согласованность и открытые вопросы `[GAP]`

- Кодировки §3 соответствуют `crates/core/src/isa.rs` и проверены тестами —
  эта часть согласована с реализацией.
- `rtsc c` (0x000E/0x000F): бит 0 слова = возвращаемый флаг C — предположение
  по дизассемблеру; в симуляторе кодируется как `0x000E | (carry as u16)`.
- Семантика косвенной адресации IR0/IR1 и точные режимы (±1) уточнены по
  дизассемблеру MC_WIN; детали сходимости на железе требуют проверки.
