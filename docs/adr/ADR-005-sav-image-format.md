# ADR-005 — Формат машинного образа `.sav`

## Статус
Принят (2026-11-03). Владелец: «без разницы» — решение принято по умолчанию
в пользу собственного канонического формата.

## 1. Контекст

Программатор фирмы работает с образом в собственном формате. Из
дистрибутива «Ангстрема» известны два разных формата:

1. **Канонический** (то, что делает наш ассемблер): ровно 1024 слова по
   16 бит, без заголовка, начиная с вектора прерываний по адресу 0x000.
   Реализован в `crates/file-format/src/sav.rs`.
2. **«Официальный»**: 256 слов заголовка, за ними образ. Именно его
   показывает `Uprg1878.exe`, и в нём есть поля, смысл которых до сих пор не
   восстановлен. Исходный формат записи на диск не найден.

Разница между ними — не в коде, а в обвязке: заголовок, контрольная сумма,
возможно, идентификатор чипа и конфигурация.

## 2. Решение

* **Канонический формат (без заголовка) остаётся основным.** Причины:
  он уже реализован и покрыт тестами, он совпадает с тем, что ожидает
  наш программатор, и в нём нет невосстановленных полей.
* Формат с заголовком не отвергнут, а **зафиксирован как отдельный
  вариант**: если оригинальный формат будет восстановлен, он добавится
  рядом, не ломая текущий (см. `crates/file-format/src/sav.rs` — там же
  описаны оба варианта и отмечено, какой из них пишется по умолчанию).
* Контрольная сумма образа — `endc_checksum3` (`crates/core/src/crc.rs`),
  три байта с переносом; правило `.endc` в ассемблере и бэкенд
  компилятора используют одно и то же.

## 3. Следствия

* Образ, полученный из C через `kr1878 compile`, неотличим от собранного
  вручную из `.mic`: тот же ассемблер, тот же формат, та же контрольная
  сумма.
* Обратная совместимость с `Uprg1878.exe` не достигнута и не является
  целью: собственный программатор (`crates/programmer`) умеет и то и другое
  по протоколу, а формат на диске — только наш.
* Если исходный формат будет восстановлен, канонический формат остаётся
  по умолчанию, а исходный включается явным флагом.

## 4. Альтернативы

* Сразу перейти на формат с заголовком — отвергнут: неизвестные поля
  пришлось бы заполнять нулями, а совместимость всё равно не проверена.
* Хранить образ в ELF — отвергнут: устройство не загружает ELF, а лишняя
  сложность не даёт ничего.

## 5. Открытые вопросы

* Точный состав 256-словного заголовка оригинального формата (если он
  когда-нибудь понадобится) — см. `CI-KNOWN-FAILURES.md`.
