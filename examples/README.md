# Примеры (скетчи)

Тестовые программы для КР1878ВЕ1 на нашем ассемблере (`.mic`, синтаксис
TESSA-совместимый).

## `blink_led.mic` — моргание светодиодом на PB0

Схема: светодиод + резистор ~330 Ом между выводом **PB0** и GND (анод к VCC,
катод через резистор к PB0 — активный низкий уровень, либо наоборот для
инверсной логики).

Что делает скетч:

1. Настраивает **PB0** как активный выход через подрегистры регистра
   конфигурации порта B (0x1A):
   - подрегистр 0 (тип вывода PT): `PT0=1` → вход/выход;
   - подрегистр 1 (тип выхода OT): `OT0=1` → активный выход;
   - подрегистр 2 (нагрузочный резистор RE): `RE0=0`.
2. В цикле: `PB0=1` → программная пауза → `PB0=0` → пауза → повтор.

Пауза реализована вложенным программным счётчиком (без таймера) — частота
моргания зависит от тактовой частоты генератора (см. конфигурационное слово
RDE/OT1/OT2 в `docs/HARDWARE_PROTOCOL.md` §7.5).

## `blink_ram.mic` — то же, но счётчики в ОЗУ

Короткая версия `blink_led.mic`: счётчики задержки живут в ОЗУ (0x40–0xBF),
а не в ЭСППЗУ-регионе, поэтому цикл на порядок короче и нагляднее для
инструкционного симулятора (`kr1878 run`).

## Исполнение на инструкционном симуляторе

Проект содержит аккуратный **исполняющий CPU-симулятор** (`kr1878-core::Cpu`):
он декодирует и выполняет каждую команду против состояния процессора
(PC/RS/SR, память данных, стеки), поэтому скетч реально «моргает» портом B.
Запуск:

```sh
cargo run -- run examples/blink_ram.mic --steps 200000 --dump
```

Вывод показывает число исполненных инструкций, состояние RS, порты A/B,
и при `--dump` — содержимое памяти данных. Проверить моргание можно, запустив
с разным числом шагов и сравнив значение `port B` (0x01 ↔ 0x00).

### Сборка

```sh
cargo run -- assemble examples/blink_led.mic --out blink_led.sav
```

### Проверка на симуляторе

```sh
cargo run -- write examples/blink_led.mic --backend sim --sim-state chip.sim
cargo run -- verify examples/blink_led.mic --backend sim --sim-state chip.sim
```

### Прошивка на реальное железо

```sh
# LPT-программатор
cargo run -- write examples/blink_led.mic --backend lpt

# USB/COM-мост (протокол официального Uprg1878.exe, write-only)
cargo run -- ports
cargo run -- write examples/blink_led.mic --backend usb --port /dev/ttyUSB0 \
  --gen quartz-high
```
